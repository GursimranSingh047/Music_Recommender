# 🎵 Music Recommendation System

## 📌 Overview
This project is a web-based music recommendation system that suggests songs based on user preferences and similarity algorithms.
It suggest music based on user mood and direct display it.

## 🚀 Features
- Song recommendation based on input
- Simple user interface
- Fast response system
- Personalized suggestions

## 🛠 Tech Stack
- Python
- Flask / FastAPI
- HTML/CSS
- Pandas
- Scikit-learn 

## 📂 Project Structure
music-recommender/
│
├── app.py
├── model/
├── static/
├── templates/
└── README.md

## ▶️ How to Run
1. Clone the repository
2. Install dependencies
3. Run `python app.py`
4. Open in browser
